隐私政策

最后更新：2025年3月

感谢您使用 TransViewer（以下简称"本应用"）。我们非常重视您的隐私与数据安全。本隐私政策用于说明我们如何处理信息。

1. 应用性质说明

本应用是一款本地运行的翻译工具：

  • 应用本身不提供翻译服务
  • 应用不运营任何服务器
  • 所有功能默认在本地执行

2. 用户数据收集情况

我们不会收集、存储或上传任何用户数据。

包括但不限于：

  • 不收集个人身份信息（姓名、邮箱、手机号等）
  • 不收集设备信息（设备 ID、IP 地址等）
  • 不收集使用行为或日志数据

3. 第三方服务（用户自行配置）

本应用支持用户自行配置第三方翻译服务 API Key（例如第三方翻译平台）。

  • 这些第三方服务由用户主动启用
  • 当您使用第三方服务时，您的请求数据（如输入的文本）可能会被发送至对应的第三方服务提供商
  • 数据的收集、处理和存储行为由该第三方服务的隐私政策决定
我们不会访问、存储或上传您的 API Key，也不会记录您的翻译内容。

4. 本地数据存储

  • 所有数据（如设置、API Key、本地记录等）仅保存在您的设备上
  • 我们无法访问或获取这些数据

5. 网络请求说明

  • 本应用本身不主动连接开发者服务器
  • 所有网络请求（如有）仅在您启用第三方翻译服务时发生
  • 这些请求由您所选择的第三方服务直接处理

6. 第三方责任声明

  • 我们不控制这些服务的行为
  • 我们不对其数据处理方式负责
  • 建议您查阅对应服务的隐私政策

7. 权限说明

本应用仅请求必要权限以实现基础功能，不会请求与功能无关的权限。

8. 儿童隐私

本应用不会主动收集任何信息，也不针对儿童进行数据收集。

9. 政策变更

如本隐私政策发生变更，我们会在应用内更新说明。
